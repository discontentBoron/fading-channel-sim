# Rayleigh Fading Channel Simulation with QPSK

A Python simulation of QPSK modulation/demodulation over Rayleigh fading channels using two different channel models.

## 📋 Description

This project simulates a QPSK communication system over Rayleigh fading channels. It supports two channel models:
- **Jakes/Smith Model** – Classical Doppler spectrum approach
- **Zheng-Xiao Model** – Statistical sum-of-sinusoids approach

The simulation computes Bit Error Rate (BER) performance across various SNR values and vehicle speeds.
